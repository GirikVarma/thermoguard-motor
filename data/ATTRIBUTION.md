Redistributed numeric profiles and embedded copies are transformed samples from this source and are shared under CC BY-SA 4.0. Changes: retain seven operating inputs and four targets, select 15 test profiles, subsample 0.5 s recordings to 2 s, and round exported values to four decimal places. Runtime faults affect copied input signals; measured reference temperatures remain unchanged.

The source authors do not endorse this prototype. The raw CSV is omitted from the submission archive. Metadata and checksum are in data/manifests/. Newly authored software and documentation are distinct from the source dataset.
