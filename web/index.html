What the result supports

Same-motor thermal estimation under replayed input faults. It does not establish cross-motor generalization, certified motor protection, or closed-loop cooling improvements.

Empirical upper bounds use a separate calibration set. Under drift or unfamiliar conditions, coverage can fall below the calibration target.

A small deep network with thermal memory

The deadline prototype uses first-order history filters inspired by thermal time constants and two learned hidden layers. It does not claim to reproduce the full proposed thermal neural network.

Learned from measured motor data

Electric Motor Temperature, Paderborn University. The source contains 1,330,816 rows across 69 sessions at 2 Hz. This demo subsamples to 2 s for thermal replay. Internal temperatures and measured torque never enter the estimator.

The models learn temperature rise over ambient. History filters and fault handling use only present and past inputs. Each profile begins with fresh history; unknown hot starts can produce large errors.

Dataset and attribution ↗

What a sensor failure means here

A reported dropout masks a measurement and provides its age. The model holds the last value for 20 s, then uses a training-derived fallback. Robust models saw similar faults during training.

Silent drift and stuck readings get no oracle flag. These are stress tests; the application does not claim to diagnose every silent fault.
